# Unjudged — You can say it here.

A beginner-friendly static website prototype for a nonjudgmental emotional-support AI.

## Files

- `index.html` — page structure and content
- `styles.css` — responsive styling
- `app.js` — chat interface and sample demo responses

## Run it locally

Open `index.html` in a modern browser. No installation is required.

## Publish with GitHub Pages or Netlify

Upload all three website files (`index.html`, `styles.css`, and `app.js`) into the root of your `unjudged-ai` GitHub repository. Keep the filenames exactly as shown.

## Important: this is a prototype

The chat currently uses local sample responses. It is **not connected to a live AI model** and should not be represented as a real AI service yet. The prototype does not send chat messages to a server or persist chat history. Before connecting a model, implement a server-side endpoint and keep API credentials in server environment variables—never in browser JavaScript or a public repository.

Before a public launch, review privacy and data retention, accessibility, safety behavior, crisis support, and the laws that apply to your audience. Do not promise absolute confidentiality or professional care.
